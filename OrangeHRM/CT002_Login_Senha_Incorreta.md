# CT002 - Login com senha incorreta

**Módulo:** Autenticação
**Tipo:** Teste funcional negativo
**Status:** Não executado

## Objetivo
Verificar se o OrangeHRM impede o
acesso com uma senha incorreta.

## Pré-condições
- Estar na página de login.
- Conhecer um usuário válido.

## Passos para execução
1. Acessar a página de login.
2. Informar um usuário válido.
3. Digitar uma senha incorreta.
4. Clicar no botão Login.

## Resultado esperado
O sistema deve impedir o acesso e
apresentar uma mensagem informando
que as credenciais são inválidas.

## Resultado obtido
Aguardando execução do teste.
