# CT001 - Login com credenciais válidas

**Módulo:** Autenticação
**Tipo:** Teste funcional positivo
**Status:** Não executado

## Objetivo
Verificar se o sistema permite o login
com usuário e senha válidos.

## Pré-condições
- Estar na página de login do OrangeHRM.
- Possuir credenciais válidas.

## Passos para execução
1. Acessar a página de login.
2. Informar um usuário válido.
3. Informar a senha correta.
4. Clicar no botão Login.

## Resultado esperado
O sistema deve autenticar o usuário
e apresentar o Dashboard.

## Resultado obtido
Aguardando execução do teste.
