# CT003 - Login com campos vazios

**Módulo:** Autenticação
**Tipo:** Teste funcional negativo
**Status:** Não executado

## Objetivo
Verificar se o OrangeHRM impede o login
quando usuário e senha estão vazios.

## Pré-condições
- Estar na página de login do OrangeHRM.

## Passos para execução
1. Acessar a página de login.
2. Deixar o campo de usuário vazio.
3. Deixar o campo de senha vazio.
4. Clicar no botão Login.

## Resultado esperado
O sistema deve impedir o acesso e
informar que os campos são obrigatórios.

## Resultado obtido
Aguardando execução do teste.
