## 🎯 Objetivo

Este projeto tem como objetivo colocar em prática os conhecimentos relacionados à Qualidade de Software e aos testes manuais.

Durante a atividade serão desenvolvidos e documentados:

- Casos de teste;
- Cenários de teste;
- Testes positivos e negativos;
- Testes funcionais;
- Testes exploratórios;
- Relatórios de bugs;
- Evidências dos testes realizados.

## 🧱 Estrutura do Repositório

O projeto está organizado em pastas para facilitar a documentação dos testes.

```text
📁 OrangeHRM
   ├── Casos de Teste
   ├── Cenários de Teste
   ├── Relatórios de Bug
   └── Evidências
```

## 🧪 Metodologia
